# 术语表（UI 与文档统一口径）

> 目的：同一个东西在页面、接口、文档里只有一个叫法。
> 出现新词先加到这里，再改代码。

## 复核与队列

| 术语 | 含义 | 不要用 |
|---|---|---|
| **待复核** | 已判定为 NG / 灰区、尚未人工确认的件 | 待确认、待处理、未处理 |
| **复核** | 人工对 NG / 灰区给出最终结论 | 审核、检查 |
| **接受 / 保持系统结论** | 人同意系统给的三态 | 确认通过 |
| **改判** | 人给出与系统相反的结论，必须选理由 | 纠正、修改 |
| **暂缓** | 现在判不了，先移出队列（可恢复） | 跳过、挂起 |
| **恢复暂缓** | 把暂缓件放回队列 | 恢复 |
| **领取** | 声明"这一件我在处理"，15 分钟超时 | 认领、锁定 |

## 编码 / 族 / 模型

| 术语 | 含义 | 不要用 |
|---|---|---|
| **族** | 设计族，一组可共用模型的编码 | 系列、family |
| **编码** | 产品编码，操作工选择的入口 | 型号、料号 |
| **件号** | 单件实例的编号，用于追溯 | 序列号、part |
| **模型** | 提供判断能力的实体 | 算法、网络 |
| **版本** | 模型的一次训练产物 | 迭代、release |
| **绑定** | 编码 → 模型的关系 | 关联、挂载 |
| **停用** | 编码/版本不可用，历史保留，可恢复 | 删除、下线 |
| **归档** | 从列表与选择器消失，仅可显式查看；有活跃绑定时禁止 | 删除 |

## 版本状态

| 值 | 中文 | 含义 |
|---|---|---|
| `candidate` | 候选 | 刚训练出来，未验证 |
| `shadow` | 影子 | 并行运行但不影响判定（v1 未用） |
| `assist` | 生效中 | 当前用于生产判定 |
| `disabled` | 已停用 | 历史版本，可重新启用 |

## 数据与训练

| 术语 | 含义 | 不要用 |
|---|---|---|
| **判定** | 一次 `/infer` 的结果（job + result） | 预测、推理结果 |
| **判例** | 人工裁决过的样本，按件唯一 | 样本、case |
| **批次** | 来料/生产批次，判定时确定 | lot、batch |
| **数据集** | 训练集快照（族 + 模型 + 判例集合），冻结后不可改 | 训练集、dataset |
| **校验和** | 数据集冻结时的内容哈希 | hash |
| **冒烟** | 用候选版本试判一张图，不写生产结果 | 测试、验证 |
| **抽检批次** | 按周抽取的盲判样本，三方签字后冻结指标 | 抽查、验收批次 |
| **盲判** | 判完才揭盲；接口层不返回系统结论 | 盲测 |

## 动作与状态（审计）

审计动作在界面上显示中文，`action` 字段保持英文枚举，映射见 `admin.html` 的 `ACTIONS` 表。新增动作必须同时加映射，否则界面会露出英文。
