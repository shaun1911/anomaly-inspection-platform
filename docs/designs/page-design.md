# 页面设计（服务端）

- 状态：Draft
- 依据：`docs/designs/工业表面缺陷检测平台-v1.md`（数据模型、门槛、CUJ）
- 目标：让页面结构服从**现场使用惯性**，而不是服从数据库表

---

## 一、设计原则

1. **待办优先**：进入系统第一眼是"要你处理的事"，不是统计图表。
2. **对象聚合**：一个编码的所有相关信息（绑定、版本、结果、判例、ROI）在一个页面里按时间线呈现，不让人跨四个菜单拼信息。
3. **量大不列表**：超过 5000 条的实体不做"能翻的列表"，做"能筛的入口 + 聚合 + 导出"。
4. **弹窗有判据**：动作 ≤3 步且 ≤30 秒、且不需要离开上下文 → 弹窗；需要滚动/对比/中断续做 → 整页。
5. **配置分层**：启动级不进页面；运行时项进设置页并记审计；版本绑定项跟模型走，不在设置页。
6. **每个页面都要有"空态"和"失败态"**，且空态要告诉人下一步做什么，不是一句"暂无数据"。

---

## 二、信息架构

```
工作台        /admin
生产          /admin#catalog
  ├ 编码详情   /admin#code=<code>
  └ 新建向导   /admin#wizard
质量          /admin#quality
  ├ 复核队列
  ├ 抽检批次
  └ 判例库
训练          /admin#training
  ├ 训练任务
  └ 版本与发布
系统          /admin#system
  ├ 站位与心跳
  └ 审计日志
设置          /admin#settings
```

左侧导航固定 6 组；顶部常驻：全局输入框（编码/`#结果号`/任务号）、环境标识、健康灯。

## 三、页面规格

### 3.1 工作台 `/admin`

**目的**：回答"我现在该干什么"。

| 区块 | 内容 | 动作 |
|---|---|---|
| 待办 | 待确认 N、待发布 M、抽检未做、站位异常 | 点条目直达对应页面并带上筛选 |
| 今日 | 判定数、NG 率、灰区率、复核分钟 | 点数字进结果检索（带当天时间窗） |
| 最近操作 | 我改过的阈值/绑定/发布（审计倒序 10 条） | 点进对象 |

- **空态**：没有任何待办时显示"今天没有待处理事项" + "下一步：去生产页建一个编码"。
- **权限**：全部角色可看；待办计数按角色过滤（操作工只看本工位）。
- **数据量**：聚合查询，单次 ≤10 条。

### 3.2 生产 `/admin#catalog`

**目的**：管理"一个产品怎么被判"。

**列表形态**：编码表（数量小，通常 <100），支持按编码/族筛选；每行显示：编码、绑定模型、版本状态、最近判定时间、待确认数。

**生命周期**：启用 → 停用（不可推图，仍可查）→ 归档（从列表与选择器消失，需先解绑）。归档不是删除，历史判定仍可按编码查。

**动作**：
- 新建编码（弹窗，3 字段）
- 归档 / 恢复（行内按钮；有活跃绑定时归档按钮禁用）
- 新建模型（弹窗，2 字段）
- 绑定/换绑（弹窗，选模型）
- 进入编码详情（整页）

**空态**："还没有编码。先建编码，再建模型并绑定，站位才能扫码换型。"

### 3.3 编码详情 `/admin#code=<code>`

**目的**：一个编码的全部事实，一屏看完。

| 区块 | 内容 |
|---|---|
| 概要 | 编码、族/零件、启用状态、当前绑定模型与版本、ROI rev、阈值 |
| 时间线 | 绑定变更、版本发布、ROI/阈值修改、异常事件（按时间倒序，可翻页） |
| 最近结果 | 最近 20 条（分数、三态、确认状态）→ 点开弹窗看证据 |
| 判例 | 该编码的判例列表（可录入） |
| 操作 | 换绑、改 ROI（产生新 `config_rev`）、改阈值（产生新 `threshold_rev`）、停用编码 |

- **弹窗**：改 ROI、改阈值、换绑、录入判例、看单条结果。
- **空态**：未绑定时显示"该编码还没有模型，去生产页绑定"。
- **权限**：技术员可改；质量员只读。

### 3.4 新建型号向导 `/admin#wizard`

**目的**：把"上样品→试跑→发布"变成线性流程，而不是并列表单。

| 步 | 内容 | 完成判据 |
|---|---|---|
| ① 基本信息 | 编码、模型名、ROI | 三者齐 |
| ② 上传样品 | 正常品/缺陷图（拖拽或多选） | 正常品 ≥100、缺陷 ≥30，否则明确提示"还差多少张" |
| ③ 训练 | 触发训练（夜间窗口） | 任务进入队列 |
| ④ 冒烟 | 3~5 张已知判例核对 | 一致率 100% |
| ⑤ 发布 | 选 shadow 或 assist | 状态位变更 |

- **形态**：整页；每步一个主按钮，可中断续做（进度存 `localStorage` + 服务端草稿）。
- **失败态**：每步失败给"重试/跳过/找技师"三个可点动作。

### 3.5 复核队列 `/admin#quality`

**目的**：处理待确认的 NG/灰区。

- **形态**：整页，左右分栏——左列表（本工位或全量，可切换），右大图 + 证据。
- **动作**：接受（一次点击）、改判（选理由）、跳过（记录原因）。
- **键盘**：`J/K` 上下、`Enter` 接受、`X` 改判——按件处理的场景必须能不用鼠标。
- **空态**："没有待确认的件。新判定为 NG/灰区时会自动出现在这里。"
- **数据量**：单次加载 50 条，滚动加载；不做页码。

### 3.6 抽检 `/admin#quality`（子页）

**目的**：每周 300 件盲判 + 三方签字。

- **形态**：整页，一批一页；批次头显示周次、抽样数、完成度。
- **流程**：逐件盲判（不显示系统结论），完成后才解锁"查看系统结论与差异"。
- **动作**：保存进度、提交并签字、导出签字单。
- **空态**："本周抽检批次未生成。生成后按提示逐件判定。"

### 3.7 判例库 `/admin#quality`（子页）

- **列表**：编码、结论、理由、裁决人、时间；筛选三件套 + 导出 CSV。
- **动作**：新增（弹窗：图 + 结论 + 一句话理由）、删除（二次确认）。
- **数据量**：分页，每页 50，服务端筛选。

### 3.8 训练 `/admin#training`

- **任务列表**：状态、模型、开始/结束、指标摘要；点开整页看日志（长文本）。
- **版本与发布**：候选对比（指标并排）、发布（弹窗二次确认）、回滚（弹窗，说明影响范围）。
- **空态**："还没有训练任务。去向导里上传样品开始第一次训练。"

### 3.9 系统 `/admin#system`

- **站位**：名称、健康、最后心跳、配置回执；异常站位高亮并可"强制同步配置"。
- **审计**：按对象/人/时间检索，结果可导出。

### 3.10 设置 `/admin#settings`

只放**运行时项**，分五组；每项显示当前值、默认值、上次修改人与时间。

| 组 | 项 |
|---|---|
| 抽样 | 每周抽检量、判定最小 NG 数、样本不足时的延长策略 |
| 判定 | 灰区上限、过杀率上限、门槛放宽规则 |
| 训练 | 夜间窗口起止、单次最长时长、失败重试次数 |
| 守门 | 最小边长、亮度下限/上限、最小对比度 |
| 理由预设 | 改判理由列表（增删排序） |

- **形态**：整页；每项行内编辑 + "保存"按钮；保存写审计。
- **禁忌**：端口、DB 路径、白名单路径**不在这里**（启动级，改了会断服务）。

## 四、弹窗清单（统一规格）

| 弹窗 | 触发 | 字段 | 危险级 |
|---|---|---|---|
| 确认判定 | 复核队列 | 结论、理由（改判时必填） | 低 |
| 新建编码 | 生产页 | 编码、族、零件 | 低 |
| 新建模型 | 生产页 | 模型编码、名称 | 低 |
| 换绑 | 编码页 | 目标模型 | 中（二次确认） |
| 改 ROI | 编码页 | 四角坐标、预览 | 中 |
| 改阈值 | 编码页 | th_lo、th_hi、理由 | 中 |
| 录入判例 | 编码页/判例库 | 图、结论、理由 | 低 |
| 发布版本 | 训练页 | 目标状态（shadow/assist）、说明 | **高**（二次确认） |
| 回滚 | 训练页 | 目标版本、影响说明 | **高**（二次确认） |
| 结果详情 | 结果列表/队列 | 只读 | 低 |

规格统一：标题 + 一句话说明 + 主按钮 + 取消；高危弹窗主按钮为红色且需输入版本号确认。

## 五、大条目页的统一模式

适用于结果、任务、审计、判例：

1. **筛选**（服务端）：时间范围、编码、三态、确认状态；
2. **保存视图**：把当前筛选存成名字（"本周 NG"），下次一键进入；
3. **导出**：当前筛选结果导出 CSV（上限 5 万行，超出提示缩小范围）；
4. **聚合条**：列表上方显示"共 N 条 / 三态分布 / 时间跨度"，替代无意义的翻页。

## 风格基线（工业极简 A+C，2026-11-15）

- 基准：`ui-ux-pro-max` 的 Minimalism / enterprise dashboard 方向；不采用玻璃拟态、深色氛围。
- 正文 15px / 1.5；圆角：区块 8px、按钮与输入 6px、卡片 6px。
- 区块标题用 **1px 细分隔线**（不用色条）：`h2{border-bottom:1px solid var(--g3)}` + 0.06em 字距。
- KPI 用**账本式一行**：`.kpi-row` 六等分、竖线分隔、外层白底细框、数字 28px/650；窄屏折两行。
- 状态只用**数字颜色 + 文字标签**表达，不再用结构色条。
- 侧边栏：分组标签 11px + 0.14em 字距 + 分隔线，菜单项 13px + 16px 内联 SVG 线性图标；选中项用 3px 内嵌品牌色标记 + 加粗。- 数字一律 `tabular-nums`；对比度基线 AA（主按钮 5.18、正文 7.56、次要 5.24）。
- 日夜主题：右上角三态（跟随系统/日间/夜间），只切 `color-scheme`，配色仍走 `light-dark()`。
- 作用域：全局生效；工作台是首个样板页。

## 复核队列页（2026-11-15 首屏可用性）

目标：1440×900 下**不滚动页面**即可完成主要复核动作。

- 筛选收成单行工具栏（6 个控件 + 重置），不再占两行带 label 的表单；
- 列表与详情两栏固定视口高度 `calc(100vh - 280px)`，列表内部滚动；
- 详情：裁片图限高 18vh，元信息 12px **两列**紧凑排布；裁片图与参考样例**并排**：左侧主图（高度随样例栏，自动放大），右侧固定 250px 样例栏，**OK/NG 分组与计数**（每组最多 2 张 + `+N`，缩略图 110px），点击打开大图弹窗；
- 四个动作合并成一行、**结果导向**：`判为 OK` / `判为 NG` / `暂缓` / `领取`；系统结论一致时对应按钮高亮且无需理由，相反结论或灰区需先选理由；`暂缓` 需理由；`领取` 只做交接标记。\n- 按钮下方一行提示说明理由规则；键盘：Enter=接受系统结论（灰区会提示先选）、O/N=判 OK/NG、1–5=选理由。\n- 全局间距同步收紧（顶栏 9px、主区 12/18、区块 12、标题下 10px），把高度让给内容而不是缩小按钮。\n- 1440×900 实测：页面 805/805、动作区 647、详情列 603/605（均不滚动）。
- 冒烟脚本断言：页面 `scrollHeight ≤ 视口高` 且动作区底部在视口内（≥1400 宽时）。

## 可发现性（交互提示，2026-11-15 审计）

审计范围：所有界面的键盘操作、回车触发、可点行、隐藏交互。

- 复核页：标题右侧「快捷键 ?」+ 底部一行提示（J/K、O/N、Enter、1–5），弹窗列全部按键；
- 盲判页：判定按钮下方提示 O/G/N；
- 全局搜索：下拉底部提示 ↑↓ / Enter / Esc；
- 回车筛选：所有筛选输入框 placeholder 写明“回车筛选”；
- 可点表格行：`title` 说明 + `tabindex=0` + Enter 打开；
- 所有 dialog 右下角统一显示「Esc 关闭」（CSS `dialog::after`）。
