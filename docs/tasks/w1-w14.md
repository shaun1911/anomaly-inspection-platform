# W1–W14 任务拆解（v1）

- 依据：`docs/designs/工业表面缺陷检测平台-v1.md`（463 行，Status: Proposed）
- 总量：**53 人日 / 14 周**（Gate 0 2 周 + 阶段 0 3 周 + 阶段 1 4 周 + 阶段 2 5 周）
- 约定：人日为含测试的估算；每项完成后在"状态"列打勾，**DoD 未满足不得进入下一项**

## 依赖与风险提示

1. **T0-1 与 T0-2 可并行**，但 T0-2 依赖 G0-1 的数据；Gate 0 未完成时只能写 `store.py` 与迁移（零依赖）。
2. **T1-3 依赖 T0-6**（判例与结果共用同一数据库连接），不要在 T0-1 未完成时开工。
3. **T2-7 回滚演练必须有第二版本**，所以排在 T2-5 之后；阶段 1 不演练回滚是刻意安排。
4. **T2-4 抽检工具决定验收能否执行**，不要压到最后一周。
5. 若 Gate 0 的"缺陷 ≥30 张"凑不齐，先走 G7 的低置信路径，不要把项目卡死在数据上。
6. 每周五更新本文档状态列，未打勾的任务不得进入下一周。
