# 工位客户端质量基线（v1）

| 项 | 目标 | 理由 |
|---|---|---|
| 安装包/压缩包 | ≤ 10 MB | 只含 exe + 说明；不携带运行时 |
| 冷启动 | ≤ 5 秒（目标机） | 工位换班/重启要快 |
| 常驻内存 | ≤ 150 MB | 与相机软件/PLC 软件共存 |
| 离线可用 | 明确降级：判定失败提示，不做离线推理/队列 | 推理依赖服务端 GPU/模型 |
| 更新策略 | v1 手工替换 exe；不自动更新 | 避免更新中断产线；后续做签名校验与回滚 |

当前实测：

- zip 约 20 KB，exe 约 43 KB；
- 启动到窗口约 1 秒（开发机）；
- 无相机/PLC 依赖。
