## 4. 任务清单（含验收与验证方式）

> 编号规则：模块前缀 + 序号。每个任务 ≤ 3 天，验收可测。

### W1
- [ ] **P1** 镜像与 compose：单镜像（app + worker），`data/`、`artifacts/`、`db/` 三个卷
  - 验收：`docker compose up -d` 后 `/health` 返回 ok
  - 验证：内网机器执行，且 `iptables` 封外网后仍启动
- [ ] **P2** 鉴权：line token（哈希）+ 管理会话；限流中间件
  - 验收：错 token → 401；超限 → 429
- [ ] **R1** SQLite 初始化与迁移脚本（含 17.2 新表）
  - 验收：空库启动自动建表；重复启动幂等

### W2
- [ ] **I1** 异步 job：`POST /infer` → 202；`GET /infer/{id}`；幂等键
  - 验收：同键重复提交 24 h 内返回同一 job_id
- [ ] **I2** 解码：`IMREAD_REDUCED_COLOR_4` + 目标尺寸校验
  - 验收：2K JPEG 解码 p95 ≤ 20 ms（`aip bench` 实测）
- [ ] **I3** 批队列：最多 8 张 / 等 8 ms，合并成一次 forward
  - 验收：8 张并发时吞吐 ≥ 150 img/s（5080 基准）
- [ ] **I4** 单模型推理接线（torch 后端，复用 `aip/runtime.py`）
  - 验收：与 offline `aip predict` 结果一致（分数差 <1e-3）
- [ ] **R2** 结果落库 + 原图/缩略图落盘（异步写，不阻塞响应）
  - 验收：推 100 张，库表与文件数量一致
- [ ] **R3** `GET /api/results`（时间/产品/判定筛选，分页）

### W3

## 5. 关键技术与风险预案

| 风险 | 触发信号 | 预案 |
|---|---|---|
| JPEG 压缩吃掉细划痕（R1） | W1 对比实验召回掉 >5pt | 改采集 Q≥90 或 ROI 裁剪送检，输入方案在 W2 前定 |
| 训练与推理抢 GPU | 训练时推理 p95 >100 ms | 训练限显存 60% + 自动暂停 + 夜间窗口 |
| 错绑模型（R8） | 冒烟集不符 | 拒绝激活 + 页面标红 + 审计 |
| 10 周不够 | W4 门禁未过 | 砍 W7~W8 自动化，保「手动训练 + 手动发布」 |
| 复核 CSV 体验差 | 用户抱怨 | 二期补回 UI（复用已有原型） |
| Windows 自动更新/睡眠导致服务中断 | 夜间掉线、重启后服务没起 | W0 基础设置脚本 + 服务自启 + 看门狗（3 次健康检查失败即重启） |
| 离线包缺依赖导致服务器装不起来 | `pip install` 报缺包 | W0 在干净虚拟机里试装一次，再打包；wheelhouse 走 `--no-index` 严格验证 |
